Chermain Scarlett - Communications Portfolio
=============================================

What's in this folder
- index.html  : the portfolio page (The Desktop design)
- assets/     : photos, screenshots, the seven videos and your CV (Chermain_Scarlett_CV.pdf)

Keep index.html and the assets folder together - the page loads everything from assets/.

Putting it online (everything works once hosted)
- Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
- GitHub Pages, Wix, Squarespace or any web host: upload index.html and the assets folder to the site's root.
- You can then connect your own domain (e.g. chermainscarlett.com) in the host's settings.

Viewing on your computer
- Double-click index.html. Most things work offline; fonts need an internet connection,
  and some browsers may block videos from local files - hosting it avoids this.

To update the CV, replace assets/Chermain_Scarlett_CV.pdf with a new file of the same name.
