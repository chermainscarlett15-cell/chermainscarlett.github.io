Chermain Scarlett - Communications Portfolio
=============================================

What's in this folder
- index.html  : the portfolio page (The Desktop design)
- assets/     : images, the four videos, T2 Kidz templates and your CV (Chermain_Scarlett_CV.pdf)

Keep index.html and the assets folder together - the page loads everything from assets/.

Putting it online
- GitHub Pages: create a repository, upload index.html, README.txt and the assets folder
  (the contents of this folder, not the folder itself), then Settings > Pages > deploy from
  the main branch, root folder.
- Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
- You can connect your own domain later in either host's settings.

Viewing on your computer
- Double-click index.html. Fonts need an internet connection, and some browsers block
  local videos - the hosted version is the one to share.

To update the CV, replace assets/Chermain_Scarlett_CV.pdf with a new file of the same name.
